# 譜台 — 視譜與爵士和弦練習器

隨機出題的鋼琴練習器。全 30 個調、雙手、四小節連續流預讀、和聲取自真實語料庫統計。
純前端，沒有建置步驟，離線可用。

**https://kubinice06-blip.github.io/piano-trainer/**

## 在 iPad 上使用

1. **用 Safari** 開啟上面那個網址（iOS 上只有 Safari 能裝成主畫面 App、
   也只有它會註冊 Service Worker；Chrome for iOS 沒有離線快取）
2. 分享鈕 → **加入主畫面**

之後就是一個全螢幕 App，沒有網路也能開（Service Worker 會把整包快取起來，
含 `vendor/vexflow.js`，所以連 CDN 全掛都不影響）。

> 更新方式：改完 push 即可。程式碼走 network-first，所以連得上網時開啟就是最新版；
> 大型靜態檔（VexFlow、圖示）走 cache-first，不會每次重抓。

## 自適應訓練系統

目前練習資料只存在這台 iPad 的 IndexedDB，不需要 Cloudflare、Firebase 或帳號。
設定抽屜可匯出 JSON 備份，也可在同一台或另一台裝置匯入還原；目前不做跨裝置同步。

- 每一段只有按下「開始」才建立實際嘗試，保存完成小節、速度、自評與選用的客觀演奏指標。
- 難度拆成音高音域、調號、節奏、織度、眼手距離、速度六軸；兩次「順」只升一軸，
  「垮掉」只降一軸，避免整份譜一起突然變難。
- 按 `X` 會保存弱點的特徵指紋，之後以相同調性、和聲骨架、節奏家族與織度重新出題，
  不是只把原題重播；順利通過後依 1／3／7 天排程複習。
- 「微練習」每站 90 秒並可獨立選 1–6 級：難度會同步改變音域／調號、節奏密度與速度、
  形狀長度與跳進距離。音名站會提高慢譜位的出題機率，節奏站用 WebAudio 拍點量點擊誤差。
- 「8 分鐘導引」先強制掃描 15 秒，再跑節奏 90 秒、音名 90 秒、連續流 4 分鐘、弱點 1 分鐘。
- 「本週 5 段測驗」固定五段難度規格、每週換新 seed、無遮蔽且固定 ♩=60；
  順暢段數、眼手距離與音名中位延遲會形成週趨勢圖。
- 演奏偵測為選用：支援 Web MIDI；iPad 麥克風只做起音時間判定。裝置不支援或未授權時，
  原本的「順／有絆／垮掉」自評流程仍可完整使用。

**iPad 上的兩個實體限制**

- **側邊的實體靜音鍵**：iOS 的 WebAudio 預設走鈴聲通道，靜音鍵一撥就沒聲。
  Safari 16.4+ 可以用 `navigator.audioSession` 繞過，但那會改變整個音訊路由，
  **預設不開** —— 預設能出聲比繞過靜音鍵重要。要用的話在設定裡自己勾。
  沒聲音時先檢查靜音鍵。
- **螢幕變暗**：勾了「練習時螢幕保持常亮」會用 Wake Lock（iOS 16.4+）。

## 操作

| 鍵盤 | | 觸控 | |
|---|---|---|---|
| `N` | 換一題 | 左滑 | 換下一題 |
| `R` | 重來同一題 | 右滑 | 開設定抽屜 |
| `P` | 播放解答音 | 點譜面 | 播放／停止 |
| `S` | 看和弦代號（視譜）／看答案（和弦） | | |
| `M` | 節拍器 | | |
| `X` | 標記「這段沒彈好」 | | |
| `H` | 左右手交換練同一段 | | |
| `↑` `↓` | 調速度（按住 Shift 一次 5） | | |

勾「開始時同步播放解答音」，按開始後解答音會在預備拍結束的正拍上進來，
跟節拍器排在同一個音訊時鐘上，不會漂。連續流換段接著播，和弦模式播完自動下一輪。

## 讀譜教練

設定抽屜的「讀譜教練」可切換到 **垂直音程**：每題四小節、每拍一音，兩手保持八度同向並在五線譜中央作隨機上下行。簡單級只用二度且方向段較長；標準加入三度；進階加入四度並增加轉向。按揭曉後用答對／答錯記錄命中率，練習紀錄會保存在本機裝置。

## 譜架版面：頁面不捲

譜架上最需要的兩顆按鈕是「開始／停止」與「換一題」。只要頁面會捲，
在 iPad 上就得先捲回去才按得到，而且 iOS 的瀏覽器工具列會在捲動時收合，
`position:fixed` 的頂欄跟著晃。

所以整個桌面固定一個視窗高（`100dvh`），**頁面本身永遠不捲**：

- 譜面在畫之前就先算好「這一列只有這麼高」，放不下時**先試一行多塞幾小節**
  （行數變少，譜還是原尺寸，比縮小划算），真的還放不下才整張縮。
- 縮小有 **85% 的下限** —— 再小就看得出來譜變小了。到了下限還放不下
  （螢幕很矮又選了 8／12 小節雙行預讀），改由**譜面區自己捲**，頁面仍然不動。
- 把「譜面大小」拉超過 100% 也一樣：譜面區捲，頁面不捲。

**矮螢幕要先把外框的留白讓出來，五線譜才不會被縮小。**
橫放的 iPad 在 Chrome 裡大約只有 740px 高，四小節連續流要擺兩段大譜表需要 547px，
但外框（頂欄、紙張留白、標題列、存檔籤）原本就吃掉近 300px。所以：

- `max-height:860px` 時，桌面／紙張／標題列的留白全部收緊（省約 44px）
- **存檔籤可以收合**，矮螢幕預設收起來（省約 55px），要看的時候點標題列展開

| iPad 橫放 1194×740 · 四小節連續流 | 譜面可用高 | 縮放 | 捲動 |
|---|---|---|---|
| 改前 | 449px | 0.80 | 0 |
| 改後（存檔籤收起，預設） | **554px** | **1.00** | 0 |
| 改後（存檔籤展開） | 499px | 0.91 | 0 |

直立 820×1024 四小節同樣是 **1.00、零捲動**（直立高度夠，存檔籤預設展開）。

**觸控裝置右下角另有一組浮動按鈕**（開始／停止、換一題），跟頂欄那兩顆連動。
在譜架上手是在鍵盤上，伸到螢幕最上緣很不順；有滑鼠的桌機不顯示。

> 過程中修掉一個實際的 bug：預讀的第二列是在 `syncRows()` 之前畫的，
> 那時它還掛著 `is-hidden`，量到的寬度是 0，繪圖端就退回寫死的 900px，
> 畫出來的譜跟容器對不起來（SVG 的 viewBox 900 卻顯示成 780 寬）。
> 改成先定版面再畫。

## 練習流程

| 流程 | 行為 |
|---|---|
| 連續流 · 預讀 | 兩行：上面是正在彈的，下面是**已經畫好的下一段**，眼睛可以先跑過去 |
| **重複同一段** | 段落彈完不換譜，游標回到第一小節重來。譜面畫上反覆記號，頂欄顯示「第 n / N 遍」 |
| 段落結束換題 | 單行，彈完就換下一段 |
| 手動換題 | 只有按「換一題」才換 |

重複的段長就是「小節數」那一欄：選 4 就是**四小節重複**、選 8 就是**八小節重複**
（也可以 2 或 12）。重複幾遍後換下一段可設 2／4／8 遍或**一直重複同一段**。
一段練熟再往前，比從頭彈到尾有用得多。

## 既有出題控制

**難度**（1–6）是六軸難度的快捷預設，會同步設定音域、調號、節奏、織度、
眼手距離與速度；需要時可再個別調整每一軸。

**音符長短**是另一條軸，決定在拿得到的節奏型裡偏好長音還是短音：
長音為主／四分音符為主／八分音符多一點／長短交錯（附點・切分）／十六分音符多一點。
選了短音會自動把對應的節奏層打開，所以在低難度也練得到八分音符的跑動；
動機變形時「把長音拆碎」的機率也跟著走。實測旋律密度從每拍 0.60 音到 1.49 音。

## 強化個別技巧

第三個軸，把旋律往某一種讀譜技巧上壓。實測（第 3–6 級 × 3 拍號 × 12 seed）：

| 強化練習 | 三度以上的音程 | 落在和弦音 | 五線之外（要加線） |
|---|---|---|---|
| 不指定 | 18.0% | 63.5% | 32.6% |
| **音程 · 三度以上跳進** | **52.8%** | 62.3% | 41.2% |
| **琶音 · 和弦分解** | **92.6%** | **100%** | 38.0% |
| **加線音 · 五線之外** | 19.8% | 62.6% | **65.0%** |

做法是三層一起調：骨架層每種音程的加分表、加花層每一步走幾度
（1 = 經過音／鄰音，2 = 三度來回）、以及「這個音算不算骨架音」的機率
（琶音是把每個音都當骨架，所以整條都落在和弦音上）。

對位規則不會因此被犧牲：換和弦時七音級進下行解決 87–92%
（跳進 75%，因為那正是它在做的事），增二度全部設定都是 **0%**。
（和聲變豐富之後，一小節兩個和弦變多、七音出現的次數也變多，
這個比例從 96% 掉到 92% —— 換來的是變化量，值得。）
練跳進時如果七音欠著一個解決，那一段空隙會強制走級進 —— 練跳進也不能欠著不還。

> 「級進」沒有做成選項：不指定時本來就有 80.5% 是級進，再加一個選項只是騙人。
> 「臨時記號」也還沒有 —— `LEVELS` 裡的 `chrom` 欄位目前是宣告了但沒接上的。

## 和弦進行的變化量

語料庫的出現次數是冪次分布，直接拿次數當權重，抽出來的東西會塌成前三名。
壓平取樣分布（`w^0.42`）之後，加上每一級都可能把一小節切成兩個和弦
（四小節、一小節一個和弦，頭尾又被「從主和弦出發」和終止式各佔掉，
中間就只剩**一個**位置可以變），變化量：

| 難度 | 改前（400 題出得到幾種） | 改後 | 最常見那一條的佔比 |
|---|---|---|---|
| 1 | 7 種 | **74 種** | 50% → 22% |
| 2 | 7 種 | **82 種** | 46% → 22% |
| 3 | 83 種 | **270 種** | 9% → 3% |
| 6 | 308 種 | **368 種** | 2% → 1% |

再加上**段與段之間不重複**：串流每產生一段，會比對佇列與最近兩段用過的進行，
撞到就換一顆 seed 重生（不是在產生器裡重抽 —— 那會讓 `usedCfg` 存不住，
回顧與列印就重現不出同一張譜）。實測連跑 41 段，相鄰重複 0、三段內重複 0。

> 壓平不會生出不存在的接續：路徑本來就只走語料庫真的有的邊，
> 改的只是每條邊被選中的機率。

## 左手的位置與轉位

**位置**：伴奏原本永遠貼著音域下緣，於是每一題的左手都從同一個 C2 開始。
現在每一題會在音域裡挑落點（以四度／八度為單位），並且不會高過旋律最低音。
實測第 3–6 級，左手最低音落在 C2 附近約 2/3、C3 附近約 1/3。

**轉位**：「練轉位」控制伴奏那隻手要不要在和聲之外再轉位。

| 設定 | 低音是和弦的第幾音（根 / 三 / 五） |
|---|---|
| 照和聲原樣 | 73% / 18% / 8% |
| 最省力（導音連接） | 55% / 26% / 17% |
| 隨機轉位 | 33% / 32% / 33% |
| 輪替 原位→第一→第二 | 41% / 29% / 28% |
| 只練第一轉位 | 6% / 75% / 19% |
| 只練第二轉位 | 18% / 5% / 73% |

預設是**依難度**：第 1–2 級照原樣，第 3 級以上用最省力（手不用跑，就是導音連接）。

> 「照和聲原樣」不等於「全部原位」—— 和聲進行本身就含 I6、V65 這類帶轉位的級數，
> 那是和聲的一部分，不是這一欄管的。

## 左右手交換練

「練習手」有**雙手 · 右手主旋律**與**雙手 · 左手主旋律**兩種。
旋律永遠寫在拿它那隻手自己的音域裡，另一隻手接下整套伴奏音型
（持續低音、根音－五音、塊狀和弦、分解和弦、阿爾貝提、
與旋律平行三／六度、與旋律反向對位）並跟著搬到對應的音域，
平行的方向也跟著換邊往上或往下疊。

抽屜裡的 **⇄ 同一段換手練** 或按 `H`：**同一段譜**換一隻手當主角 ——
seed、調、和聲、和聲節奏全部不動，只有分工對調。

**手的位置**：伴奏的低音現在會主動貼到音域該貼的那一端（在旋律下方就貼下緣、
在上方就貼上緣），其餘和弦音往上疊。舊寫法只做「超出音域才移八度」，
於是和弦常常整團停在音域頂端 —— 實測第 4 級有 30% 的小節左手爬到右手旋律上面去。
修正後 4,776 個小節裡兩手交叉只剩 15 個（0.3%），而且都出現在第 5、6 級的
平行／反向對位，那是聲部本來就會偶爾交錯的寫法。

## 和弦模式

進行 28 條（基礎／代理／藍調／曲式／調式）× voicing 9 種（含兩種雙手）
× 節奏 7 種 comping + 分解和弦上行／下行／上下行 + 走路低音。
節拍器跑起來時，游標會沿著整條進行走，走到底自動繞回第一小節。

## 兩種「回顧」

- **本次練習存檔**（譜面下方）：連續流每推進一段就建檔，可即時調閱。
  **按「換一題」或改任何出題設定就清空** —— 那代表換了一個新題目。
- **長期練習紀錄**（設定抽屜內）：跨場次保存，關掉瀏覽器再開還在。
  按 `X` 標記卡住的段落進複習清單，可隨時調閱重練，或整批列印成 A4 練習單。
  統計裡的「最常卡住」看的是標記率而不是次數，而且要練過 3 次以上才納入排名。

## 和聲資料來源

`js/data/harmony-stats.js` 由 `tools/build-harmony-stats.mjs` 從
[When-in-Rome](https://github.com/MarkGotham/When-in-Rome) 功能和聲語料庫萃取
（分析部分採 CC BY-SA 4.0）：921 份分析、3,597 個調性段落、49,785 個和弦。
含 Bach、Mozart、Schubert、Fanny Mendelssohn、Clara Schumann、Monteverdi，
以及 Reger、Rimsky-Korsakov、Tchaikovsky、Kostka 的和聲學教科書習題。

該工具只下載、只計數、只輸出出現頻率，原始分析檔不落地也不進版控。

重新產生：

```bash
node tools/build-harmony-stats.mjs
node tools/make-icons.mjs
```
